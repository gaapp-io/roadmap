# Gaapp.io roadmap

Public roadmap and changelog for [Gaapp.io](https://gaapp.io), goal planning from year to day.

This is the one place that says what comes next and what shipped. Dates are targets. Updated 2026-11-06.

**Feedback:** open a thread in [Discussions](https://github.com/gaapp-io/roadmap/discussions). Ideas, questions and bug reports all go there. Tristan reads every thread and answers within a few days.

## Now

- API v1: scopes for personal API keys, versioned responses, a documentation page. The MCP server moves onto the same functions as the REST API.
- Email reminders and lifecycle mails: weekly review, nudges when a goal goes quiet
- New Year planning pages and templates for goal agreements and employee reviews, in English and German

## Next

- Team plans with monthly goal conversations
- Company view with roles, invoicing for companies, data processing agreement
- Week planning: carry open goals into the new week; month view in the calendar

## Later

Ideas, not scheduled.

- Connectors beyond the API and MCP: webhooks, calendar sync beyond the ICS feed
- Drag and drop for goals, streaks, offline mode
- More themes

## Not planned

- Enterprise OKR suites with approval workflows. Gaapp stays small and calm.
