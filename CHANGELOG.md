# Changelog

Newest first. Only what is live at [gaapp.io](https://gaapp.io).

## 2026-11-06: State of the app

This changelog starts today. What exists as of 2026-11-06:

- Goal chain from year to day with progress roll-up, goal templates, SMART assistant for yearly goals
- Calendar week view
- Shared spaces for teams and coaches, with permissions per member
- AI planner that drafts a plan from a goal
- Analytics, dark mode, keyboard shortcuts
- REST API under `/api/public/v1` with personal API keys on paid plans
- MCP server at `/mcp` with OAuth: list spaces, list goals, create a goal, check a goal off
- English and German, blog in both languages

Live since 2026-09-11.
